# 사유
# ============================================================
# opencv-python   : 표 선 검출 핵심 라이브러리. Canny 엣지, 허프변환, CLAHE, 적응형 이진화, 모폴로지 연산, 셀 그리기 등에 사용
# numpy           : 이미지 배열 연산, 각도 median 계산, 좌표 클러스터링 등 수치 처리에 사용
# matplotlib      : 검출된 표선·grid·최종 셀 결과를 화면에 시각화(show)하는 데 사용
# pillow          : cv2.imread가 실패하는 비표준 이미지 포맷을 대체로 읽어들이는 로더로 사용
# contourpy       : matplotlib가 등고선(contour) 그릴 때 내부적으로 사용 (matplotlib 하위 의존성)
# cycler          : matplotlib가 색상/스타일 순환 지정할 때 사용 (matplotlib 하위 의존성)
# fonttools       : matplotlib가 텍스트/폰트 렌더링할 때 사용 (matplotlib 하위 의존성)
# kiwisolver      : matplotlib가 레이아웃(축, 여백 등) 제약을 계산할 때 사용 (matplotlib 하위 의존성)
# packaging       : matplotlib가 버전 문자열을 비교/파싱할 때 사용 (matplotlib 하위 의존성)
# pyparsing       : matplotlib가 수식/스타일 문자열을 파싱할 때 사용 (matplotlib 하위 의존성)
# python-dateutil : matplotlib가 날짜/시간 축을 다룰 때 사용 (matplotlib 하위 의존성)
# six             : python-dateutil이 Python 2/3 호환 코드를 위해 사용 (python-dateutil 하위 의존성)
