# OpenCV 기반 표 구조 입력 검출 방식 비교 및 실패 유형 분석

## 1. 연구 목적

본 실험은 부동산 임대차계약서 이미지에서 표 구조 복원에 활용할 셀 후보 영역을 검출하기 위해 Morphological Opening 기반 Grid 방식과 Contour 기반 방식을 비교·분석하였다.

두 방식의 검출 결과를 동일한 Ground Truth(GT)와 비교하여 셀 검출 성능을 정량적으로 평가하였으며, 주요 파라미터 변화에 따른 민감도와 실패 유형을 분석하였다.

본 실험은 최종 Field Accuracy를 직접 평가하기 위한 것이 아니라, OpenCV 기반 구조 복원 단계에서 사용할 입력 검출 방식의 선정 근거와 한계를 제시하기 위한 보조 실험이다.

## 2. 실험 방법 (Method)

### 2.1 실험 데이터 및 평가 환경

실험에는 3000 × 4000 픽셀 크기의 부동산 임대차계약서 이미지(`sample.jpg`)를 사용하였다.

Ground Truth는 총 10개의 셀로 구성되며, 일반 셀(General Cell) 5개와 병합 셀(Merged Cell) 5개를 포함한다. 각 셀의 좌표는 `[x1, y1, x2, y2]` 형식으로 정의하였다.

두 검출 방식 모두 동일한 이미지와 GT를 사용하였으며, IoU 임계값 0.3, 0.5, 0.7에서 TP, FP, FN, Precision, Recall 및 F1-Score를 측정하였다.

### 2.2 Morphological Opening 기반 Grid 검출

Morphology 방식에서는 이미지 전처리 후 수평 및 수직 방향의 Morphological Opening을 통해 표 구조선을 추출하였다.

추출된 선분을 바탕으로 행·열 경계 좌표를 구성하고, 인접한 경계 좌표를 이용하여 셀 Bounding Box를 생성하였다.

수평·수직 구조선 추출에 사용되는 h/v ratio를 0.03, 0.05, 0.08로 변경하여 파라미터 변화가 구조선 보존 및 셀 검출 성능에 미치는 영향을 분석하였다.

### 2.3 Contour 기반 셀 검출

Contour 방식에서는 이미지의 그레이스케일 변환, CLAHE 대비 개선, Adaptive Threshold 및 Morphological Closing을 수행한 후 OpenCV의 `findContours`를 이용하여 윤곽선을 검출하였다.

검출된 윤곽선에 대해 Bounding Box를 생성하고, 최소 너비와 높이 기준을 적용하여 후보 영역을 필터링하였다.

최소 너비/높이 조건은 30/15, 50/20, 70/30 픽셀로 설정하였다.

### 2.4 정량 평가

검출된 Bounding Box와 GT 간 IoU를 계산하여 일반 셀과 병합 셀을 구분해 평가하였다.

Precision, Recall, F1-Score는 다음과 같이 계산하였다.

- Precision = TP / (TP + FP)
- Recall = TP / (TP + FN)
- F1-Score = 2 × Precision × Recall / (Precision + Recall)

방식 간 대표 비교에는 IoU 0.5를 적용하였다. 일반 셀과 병합 셀의 TP·FP·FN을 각각 합산하여 통합 지표를 계산하였으며, 배경 오검출은 별도 항목으로 분석하였다.

## 3. 실험 결과 (Results)

### 3.1 검출 방식별 성능 비교

**표 1. IoU 0.5 기준 Morphology 및 Contour 성능 비교**

| 방식 | 설정 | BBox 수 | Precision | Recall | F1 |
|---|---|---:|---:|---:|---:|
| Morphology | 0.03 | 416 | 1.1% | 10.0% | 2.0% |
| Morphology | 0.05 | 148 | 4.0% | 20.0% | 6.7% |
| Morphology | 0.08 | 26 | 0.0% | 0.0% | 0.0% |
| Contour | 30/15 | 1,348 | 6.3% | 80.0% | 11.7% |
| Contour | 50/20 | 263 | 15.7% | 80.0% | 26.2% |
| **Contour** | **70/30** | **219** | **18.2%** | **80.0%** | **29.6%** |

*주: Precision, Recall, F1은 일반 셀과 병합 셀의 TP·FP·FN을 합산하여 계산한 micro 지표이며, 배경 FP는 제외하였다.*

실험 결과, Morphology 방식에서는 h/v ratio 0.05가 가장 높은 F1-Score인 6.7%를 기록하였다.

Contour 방식에서는 최소 너비/높이 70/30 설정이 F1-Score 29.6%로 가장 높은 성능을 나타냈다.

해당 설정은 전체 여섯 가지 설정 중 가장 높은 통합 F1-Score를 기록하였으며, 평가된 조건 내에서 구조 복원 입력을 위한 가장 유리한 검출 후보로 선정하였다.

### 3.2 Morphology 파라미터 민감도

**표 2. Morphology h/v ratio에 따른 검출 결과**

| h/v ratio | BBox 수 | 배경 FP | F1 (IoU 0.5) |
|---|---:|---:|---:|
| 0.03 | 416 | 327 | 2.0% |
| **0.05** | **148** | **98** | **6.7%** |
| 0.08 | 26 | 19 | 0.0% |

h/v ratio가 증가함에 따라 생성된 Bounding Box 수와 배경 오검출 수가 감소하였다.

그러나 0.08 설정에서는 유효한 구조선도 상당 부분 제거되어 일반 셀과 병합 셀 모두 IoU 0.5 기준으로 정답 검출에 실패하였다.

이는 형태학적 연산의 커널 크기 설정이 불필요한 선분 제거뿐 아니라 실제 셀 경계의 보존에도 직접적인 영향을 미친다는 점을 보여준다.

### 3.3 Contour 크기 필터 민감도

**표 3. Contour 최소 크기 필터에 따른 검출 결과**

| 최소 w/h | BBox 수 | 배경 FP | F1 (IoU 0.5) |
|---|---:|---:|---:|
| 30/15 | 1,348 | 1,221 | 11.7% |
| 50/20 | 263 | 212 | 26.2% |
| **70/30** | **219** | **175** | **29.6%** |

최소 크기 필터를 강화할수록 검출된 Bounding Box 수가 감소하였다.

30/15에서 70/30으로 변경했을 때 Bounding Box 수는 약 83.8%, 배경 오검출 수는 약 85.7% 감소하였다.

반면 IoU 0.5 기준 일반 셀과 병합 셀의 통합 Recall은 세 설정 모두 80.0%로 유지되었다.

이는 본 실험 범위에서 크기 필터링이 정답 셀 검출률을 유지하면서 불필요한 후보 영역을 줄이는 데 효과적이었음을 보여준다.

### 3.4 IoU 임계값에 따른 검출 특성

**표 4. 최적 설정의 IoU별 성능**

| 방식 | IoU | 일반 셀 F1 | 병합 셀 F1 |
|---|---:|---:|---:|
| Morphology 0.05 | 0.3 | 22.2% | 14.3% |
| Morphology 0.05 | 0.5 | 0.0% | 9.5% |
| Morphology 0.05 | 0.7 | 0.0% | 9.5% |
| Contour 70/30 | 0.3 | 50.0% | 23.5% |
| Contour 70/30 | 0.5 | 50.0% | 17.6% |
| Contour 70/30 | 0.7 | 50.0% | 11.8% |

Contour 70/30에서는 IoU 임계값이 0.3에서 0.7로 증가하더라도 일반 셀 F1-Score가 50.0%로 유지되었다.

반면 병합 셀 F1-Score는 23.5%에서 11.8%로 감소하였다. 이는 병합 셀 후보의 경계가 GT와 충분히 일치하지 않는 사례가 존재함을 시사한다.

## 4. 실패 유형 분석 (Failure Analysis)

**표 5. 구조 입력 검출 단계의 주요 실패 유형**

| 실패 유형 | 관찰 및 분석 |
|---|---|
| 짧은 내부 선 누락 | Morphology 커널 비율이 증가하면서 짧은 경계선이 제거되어 셀 구조 정보가 손실됨 |
| 끊어진 표선 | 수평·수직 선분이 불연속적으로 추출되어 완전한 셀 경계 구성이 어려워짐 |
| 희미한 선 누락 | 일부 약한 표선이 전처리 및 구조선 추출 과정에서 유지되지 않음 |
| 표선·글자 간섭 | Contour 전처리 결과에 표선과 문자 획이 함께 남아 비셀 영역의 후보 검출 가능성이 발생함 |
| 과도한 후보 생성 | Contour 30/15에서 1,348개의 BBox가 생성되어 배경 FP가 크게 증가함 |
| 병합 셀 경계 불일치 | 높은 IoU 기준에서 병합 셀 TP가 감소하여 경계 정합성의 한계가 나타남 |

*주: 텍스트 획 오검출, 중복 Contour 및 셀 내부 사각 요소의 개별 발생 건수는 별도로 측정되지 않았다.*

## 5. 논의 (Discussion)

본 실험에서는 Morphological Opening 기반 Grid 방식과 Contour 기반 방식이 서로 다른 실패 특성을 보였다.

Morphology 방식은 표의 수평·수직 구조선을 직접 추출할 수 있다는 장점이 있으나, 커널 비율에 따라 선분이 과도하게 제거되는 문제가 발생하였다. 특히 짧거나 불연속적인 경계선이 손실되면 셀 후보 영역의 생성이 어려워졌으며, h/v ratio 0.08에서는 IoU 0.5 기준으로 유효한 셀을 검출하지 못하였다.

반면 Contour 방식은 최소 크기 필터링을 통해 불필요한 검출 후보를 효과적으로 감소시킬 수 있었다. 특히 70/30 설정은 전체 여섯 설정 중 가장 높은 통합 F1-Score를 기록하였으며, 일반 셀 검출 성능도 상대적으로 안정적으로 유지되었다.

그러나 Contour 방식 역시 완전한 표 구조 복원을 보장하지는 않았다. 병합 셀의 경우 IoU 임계값이 높아질수록 검출 성능이 감소하였으며, 문자 획과 표선이 혼재된 영역에서는 불필요한 후보가 발생할 가능성이 존재하였다.

따라서 본 실험 결과는 Contour 기반 검출이 평가 대상 계약서에서 상대적으로 유리한 구조 입력 후보를 제공한다는 근거로 활용할 수 있으나, 병합 셀 경계 보정과 오검출 후보 제거 등 후속 구조 복원 단계의 필요성을 함께 보여준다.

또한 본 실험은 단일 계약서 이미지와 10개의 GT 셀을 대상으로 수행되었으므로, 다양한 문서 양식에 대한 일반화 성능을 입증하지는 않는다.

## 6. 최종 검출 방식 선정 및 결과물

최종 구조 입력 검출 후보로 **Contour 기반 방식의 최소 너비/높이 70/30 설정**을 선정하였다.

선정 근거는 다음과 같다.

1. IoU 0.5 기준 가장 높은 통합 F1-Score(29.6%) 기록
2. 일반 셀과 병합 셀의 통합 Recall 80.0% 확보
3. Contour 설정 중 가장 적은 배경 FP(175개) 기록
4. 219개의 Bounding Box를 후속 처리가 가능한 JSON 형식으로 저장

최종 검출 결과는 `contour_best_bbox.json`으로 저장하였다.

해당 파일은 검출 방식, 파라미터, 이미지 ID, Bounding Box 개수 및 좌표 목록을 포함하며, 구조 복원 후속 단계에서 입력 후보 데이터로 활용할 수 있다.

## 7. 결론

본 보조 실험에서는 Morphological Opening 기반 Grid 검출과 Contour 기반 검출을 비교하여 구조 입력 검출 방식의 파라미터 민감도 및 실패 유형을 분석하였다.

실험 결과, Morphology 방식은 커널 비율 증가에 따른 구조선 손실이 주요 한계로 나타났으며, Contour 방식은 최소 크기 필터를 통해 오검출을 감소시키는 효과를 보였다.

평가된 조건 내에서는 Contour 70/30 설정이 가장 높은 검출 성능을 기록하였으며, 이를 구조 복원 단계의 입력 검출 후보로 선정하였다.

본 결과는 최종 Field Accuracy를 직접 설명하는 지표가 아니라, 구조 입력 방식의 선정 근거 및 오류 분석을 제공하는 보조 실험 결과로 활용된다.
