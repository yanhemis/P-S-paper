# P-S-paper

## 작업 개요
- 한국어 부동산 임대차계약서의 표(Table) 구조 및 셀(Cell) 단위 정밀 추출 가능 여부 검증을 위한 딥러닝 모델별 테스트 수행

## 모델별 테스트 결과 요약
1. PaddleOCR (PP-Structure): 레이아웃 모델의 한국어 지원 불가로 구동 실패
2. Table Transformer (TATR): 표 및 행/열 뼈대 검출은 우수하나, 병합된 미세 셀 단위 분리 불가 및 OCR 미지원
3. LayoutParser: Windows 환경 Detectron2 의존성 충돌 및 한국어 문서 서식 데이터 부재
4. PaddleOCR (SLANet): 영어 모델 우회 구동 시 계약서 서식 미인지로 셀 병합 구조 붕괴 (엑셀 A열 1차원 나열)

## 최종 제안 방향
- 단일 딥러닝 모델의 국내 계약서 적용 한계 확인
- OpenCV 기반 물리적 선/셀 검출 + PaddleOCR(한글) 텍스트 추출 하이브리드 파이프라인 채택 제안

##  참고 사항
- 세부 코드 및 테스트 이력은 각 기능 브랜치에 기록되어 있습니다.
