# P-S-paper

# 📄 부동산 임대차계약서 표 구조(Table Structure) 정밀 추출 모델 비교 분석 보고서

본 프로젝트는 딥러닝 기반의 문서 레이아웃 분석 및 표 구조 인식 모델 4종을 테스트하여, **한국어 임대차계약서 이미지 내의 복잡한 표(병합 셀 포함) 구조와 셀 단위 Bounding Box 좌표를 정밀하게 추출할 수 있는지 검증**한 결과입니다.

---

## 💻 1. 실행 환경 (Environment)
* **OS:** Windows 11 (Local PC)
* **Language:** Python 3.11 (venv 권장)
* **Hardware:** AMD Ryzen 5 5600X / 16GB RAM (GPU 비활성화, 순수 CPU 추론 연산)
* **Core Libraries:** `paddlepaddle==2.6.2`, `paddleocr==2.8.1`, `transformers`, `torch`, `opencv-python`

---

## 2. 라이브러리 및 모델 비교표 (필수 확인 사항 종합)

| 모델 | 실행 성공 | Text bbox | Cell bbox | 병합 셀 | 한국어 OCR | 한계/제외 사유 |
| :--- | :---: | :---: | :---: | :---: | :---: | :--- |

| **LayoutParser** | 환경 의존 | 평가 불가 | 평가 불가 | 평가 불가 | - | 환경 문제 |

## 📂 3. 폴더별 테스트 상세 내역 및 검출 결과

각 폴더별로 독립적인 테스트 코드가 구성되어 있습니다. 각 폴더로 이동하여 `python test.py`를 실행하면 결과를 확인할 수 있습니다.

### `1_PP-Structure` (PaddleOCR 내장 레이아웃 엔진)
* **간단한 테스트 방법:** 폴더 내 `test.py` 실행
* **검출 결과:** 실행 불가
* **실행하지 못한 이유 및 필요한 환경:** 모듈 내부에 영어(`en`)와 중국어(`ch`)만 지원하도록 하드코딩되어 있어, `lang='korean'` 설정 시 런타임 에러가 발생하며 원천 차단됨.

### `2_TATR` (Microsoft Table Transformer)
* **간단한 테스트 방법:** `pip install transformers timm` 후 `test.py` 실행
* **검출 결과:** `tatr_result.jpg` (셀 BBox 표시 결과 이미지 생성 확인)
* **실행하지 못한 이유(한계점):** 표의 큰 뼈대(행/열) Bounding Box는 고정확도로 검출하나, 계약서 특유의 복잡하게 병합된 개별 칸(보증금, 인적사항 등) 단위까지는 세밀하게 쪼개지 못하며 내부 한글 텍스트 OCR 기능이 부재함.

### `3_LayoutParser` (Detectron2 기반 레이아웃 분할)
* **간단한 테스트 방법:** `pip install layoutparser` 후 `test.py` 실행
* **검출 결과:** 환경 충돌로 인한 실행 실패
* **실행하지 못한 이유 및 필요한 환경:** 핵심 백본인 Detectron2가 Windows/CPU 환경에서 C++ 컴파일러 및 PyTorch 의존성 충돌을 일으킴. 영문 사전 학습 모델 위주라 한국어 서식 적용을 위해서는 대규모 라벨링 데이터와 GPU 학습 환경이 추가로 필요함.

### `4_SLANet` (PaddleOCR 표 구조 특화 모델)
* **간단한 테스트 방법:** `pip install premailer openpyxl` 후 `test.py` 실행
* **검출 결과:** 174개 Bbox 검출 후 엑셀 변환 (결과물: `output_table/contract_table_result.xlsx`)
* **실행하지 못한 이유(한계점):** 한글 미지원 에러를 피하고자 강제로 영어(`lang='en'`) 구동 시, 텍스트와 계약서 폼을 인지하지 못해 엑셀 병합(Colspan) 기준점을 상실함. 그 결과 엑셀 A열 하나에 모든 내용이 세로로 우겨넣어지는 치명적 레이아웃 붕괴 발생.

## 🏆 4. 최종 결론 및 추천 후보 

**최종 추천 파이프라인: [OpenCV (물리적 셀 분할) + PaddleOCR (한글 텍스트 정밀 추출)] 하이브리드 방식**

단일 딥러닝 모델 4종을 테스트한 결과, 한국어 폰트와 국내 임대차계약서의 복잡한 병합 표 구조 앞에서는 **모두 심각한 레이아웃 붕괴, 세부 셀 분리 불가, 환경 충돌 등의 치명적 한계**를 보였습니다. 

따라서 언어 모델에 의존하여 구조를 추론하는 대신, **OpenCV 이미지 처리 기술을 통해 픽셀 기반으로 표의 선(Line)을 직접 찾아 칸(ROI)을 완벽하게 오려낸 후, 각 칸마다 한국어 인식률이 높은 PaddleOCR을 씌우는 방식**이 현재로서는 가장 확실하고 빠르며, 도입 난이도가 낮은 최적의 대안으로 판단됩니다.
