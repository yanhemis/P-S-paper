# 추가 인원 A 전달: ROI OCR용 셀 결과 (sample.jpg)

## 전달 파일
| 파일 | 내용 |
|---|---|
| `cells.json` | 셀 좌표 86개 (general 41 / merged 45) |
| `sample_aligned.png` | 좌표 기준 이미지 (원본을 -1.06° 기울기 보정) |
| `roi/` | 셀별 크롭 이미지 86장. 파일 이름 앞 숫자 = 셀 id (예: `023_merged.png` = id 23) |

## 좌표 사용법
- `cells.json`의 bbox는 `sample_aligned.png` 기준 `[x1, y1, x2, y2]` (원본 sample.jpg 기준 아님)
- 자를 때: `img[y1:y2, x1:x2]`. 가장자리 표선을 피하려면 3~5px 안쪽으로 자르기 권장
```python
import json, cv2
cells = json.load(open("cells.json", encoding="utf-8"))["cells"]
img = cv2.imread("sample_aligned.png")
x1, y1, x2, y2 = cells[23]["bbox"]          # 보증금 금액 칸
roi = img[y1 + 4:y2 - 4, x1 + 4:x2 - 4]
```

## 주의
1. **한 칸에 여러 필드**: 23·25·27·29·31번은 금액과 영수자·지급일 등이 한 칸에 같이 있음 → 칸 안에서 다시 나눠 읽는 후처리 필요
2. **라벨과 값이 합쳐진 칸**: 43·59(대리인 주소), 74·76(서명및날인), 78·80(등록번호 + 전화), 85번은 짧은 세로선을 놓쳐 인쇄 라벨 글자가 같이 들어 있음
3. **가장자리 글자 잘림**: 촬영 원근 때문에 맨 왼쪽 열은 첫 글자가 조금 잘릴 수 있음
