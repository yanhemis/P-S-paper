# H1 — 이미지 품질과 인쇄 글자 / 손글씨 인식

- 인쇄 글자: 양식 PDF 텍스트 레이어의 한글(세로 라벨 제외 53줄, 1,325자). 10장 모두 내용이 같아서 이미지 품질만 다르다
