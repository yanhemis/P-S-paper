# 최종 평가 총괄 — Evaluation Gatekeeper

**담당:** `dahye_cell_DetectionSurvey`  
**정리 기준일:** 2026-11-04  
**검토 예정:** 2026-11-05  
**상태:** 기존 공통 10장 평가 검증 완료 / 신규 데이터 최종 평가 대기

## 1. 담당 업무

정형 임대차계약서 핵심정보 추출 연구에서 P0~P4 파이프라인을 동일한 기준으로 평가하고, 단계별 오류 전파와 실패 원인을 분석한다.

평가 대상 핵심 필드는 다음 5개이다.

- `address` — 소재지
- `deposit` — 보증금
- `contract_amount` — 계약금
- `lessor_name` — 임대인 성명
- `lessee_name` — 임차인 성명

주요 평가 지표는 Field Accuracy, CER, ROI Coverage, 실행 시간 및 실패 유형이다.

## 2. 기존 공통 10장 평가 결과

기존 공통 이미지 10장 중 계약금 GT가 없는 1건을 제외해 총 **49개 필드 인스턴스**를 평가했다.

| 파이프라인 | Field Accuracy | 평균 CER | OCR 시간(sec/image) |
|---|---:|---:|---:|
| P0 Raw Full OCR | 29/49 (59.2%) | 0.141 | 29.32 |
| P1 Rectified Full OCR | 31/49 (63.3%) | 0.120 | 31.13 |
| P2 GT ROI OCR | 31/49 (63.3%) | 0.117 | 0.93 |
| P3 Detected ROI OCR | 13/49 (26.5%) | 0.985 | 0.95 |

**해석 시 주의사항**

- 위 수치는 기존 공통 10장의 역사적 평가 결과이며, 신규 데이터 또는 최종 holdout 결과가 아니다.
- P0/P1은 GT ROI 정보를 필드 대응에 사용했으므로 완전히 GT 독립적인 End-to-End 성능이 아니다.
- P2는 정답 ROI를 제공한 실험으로 자동 ROI 검출 성능을 평가하지 않는다.
- P3의 ROI 관련 필드 기록은 22/49건(44.9%)이지만, 이는 **ROI 결과 레코드 존재율**이며 실제 공간적 ROI Coverage와 동일하지 않다.
- 기존 P3는 필드별 GT ROI와의 겹침을 이용한 검출 셀 선택이 포함돼 있어 완전 자동 필드 탐지로 해석하면 안 된다.
- 실행 시간은 전체 파이프라인 비용이 동일하게 포함된 값이 아니므로 직접적인 속도 순위로 사용하지 않는다.

자세한 비교 및 평가 조건은 [공통 10장 비교 보고서](common10_final_comparison.md)에 정리했다.

## 3. P4 Anchor ROI 평가 현황

태구 브랜치의 최신 결과를 기준으로 `sample.jpg` **1장**에 대해 다음 결과를 확인했다.

| 항목 | 결과 |
|---|---|
| 평가 이미지 | 1장 |
| 평가 필드 | 5개 |
| ROI 생성 | 5/5 |
| Raw Exact Match | **4/5 (80.0%)** |
| 실패 필드 | 주소 (`4층`의 `층` 누락) |
| 기록된 실행 시간 | 약 11.94초 |
| 실행 조건 | 해당 이미지의 1차 OCR 캐시 재사용 |

P4는 아직 공통 10장 및 신규 데이터 전체에 대한 평가가 아니다. 또한 캐시를 재사용한 실행이므로 처리 시간을 다른 파이프라인과 직접 비교하지 않는다.

따라서 현재 P4는 **단일 이미지 PoC/보조 비교 결과**로 구분한다.

## 4. 금액 정규화 검증

신규 평가 규격에 맞춰 보증금과 계약금의 금액을 원 단위 숫자 문자열로 표현하는 정규화 코드를 작성했다.

검증 결과:

- 정규화 단위 테스트: **14/14 통과**
- 기존 계약금 GT 변환: **9/9 성공**
- 계약금 숫자 기준 정확도:
  - P0: **6/9**
  - P1: **5/9**
  - P2: **7/9**
  - P3: **0/9**

해석 불가능한 OCR 문자열은 임의로 정답으로 보정하지 않았다.

이 결과는 **계약금 필드에 대한 별도 검증**이며, 기존 전체 49개 필드 평가표의 수치를 대체하지 않는다. 최종 평가 규칙은 아직 동결 전이다.

## 6. 신규 데이터 및 최종 평가 진행 상태

2026-11-04 확인 기준:

- `heewon` 브랜치: 신규 촬영 이미지 6장 확인
- `tail` 브랜치: 신규 촬영 이미지 9장 및 촬영 조건용 `manifest_tail.csv` 확인
- `taegu` 브랜치: P4 단일 이미지 End-to-End 실험 결과 확인
- 가은 학우님 담당 **통합 Dataset v1.0 (`manifest.csv`, `field_gt.json`, 그룹별 split) 최종 전달물은 아직 확인되지 않음**

촬영 파일이 존재한다고 해서 통합 GT 검수와 development/holdout 분리가 완료된 것으로 간주하지 않는다.

최종 평가를 위해 남은 항목은 다음과 같다.

1. Dataset v1.0 및 핵심 5필드 GT 인수·검증
2. P0~P4의 필드 키, 정규화 규칙 및 평가 분모 확정
3. bang/taegu 파이프라인의 코드 버전 동결과 개발 데이터 결과 수령
4. 동일 기준의 ROI Coverage, Field Accuracy, CER 및 failure breakdown 산출
5. 동결 이후 공개된 holdout 데이터에 대한 최종 1회 평가

**holdout은 코드와 규칙 동결 전까지 평가하지 않는다.**

## 7. 최종 검토 시 참고사항

현재 제출된 수치는 기존 데이터에 대한 검증 결과와 P4 단일 이미지 실험 결과이다. 신규 Dataset v1.0을 사용한 P0~P4 통합 비교 및 holdout 결과는 아직 확정되지 않았다.

평가의 재현성, 분모 일치성, GT 사용 조건, ROI 누락 처리 및 데이터 누수를 구분하여 최종 논문 수치의 신뢰성을 확보하는 것을 목표로 한다.
